# 别墅轰趴 — 用户操作手册

## 一、用户端（微信小程序 / Web）

### 1. 注册与登录

**微信小程序：**
1. 微信搜索"别墅轰趴"小程序，点击进入
2. 首次进入会弹出授权窗口，点击"允许"完成微信登录
3. 登录后自动获取微信头像和昵称

**Web端：**
1. 访问平台首页，点击右上角"登录"
2. 使用手机号或微信扫码登录
3. 首次登录可设置昵称

### 2. 搜索别墅

1. 首页顶部输入关键词（别墅名称、地址），按回车或点击搜索
2. 使用场景标签快速筛选：团建、生日、聚会、亲子
3. 进入搜索页后可进一步筛选：
   - **人数**：选择入住人数范围
   - **价格范围**：拖动滑块设置预算（0-10000元/晚）
   - **房间数**：选择最少房间数
   - **设施**：点亮需要的设施标签（泳池、KTV、棋牌等）
4. 支持按价格升序/降序、评分排序
5. 当前筛选条件会显示在顶部，可一键清除

### 3. 查看别墅详情

1. 点击别墅卡片进入详情页
2. 页面包含：
   - **图片相册**：左侧大图 + 右侧缩略图，点击可放大浏览
   - **基本信息**：名称、地址、可住人数、卧室数、面积
   - **价格信息**：基础价（平日）、周末价、押金、连住折扣（3/5/7天）
   - **设施标签**：该别墅拥有的设施一览
   - **用户评价**：多维度评分（清洁度、设施、位置、性价比）、视频测评、文字评论
   - **视频测评**：横向滑动浏览真实入住者的视频评价
3. 评论支持按"最新/最高评分/最低评分"排序

### 4. 预订别墅

1. 在别墅详情页点击"立即预订"
2. **选择日期**：
   - 日历中绿色日期可选，灰色日期已被预订或不可用
   - 不可选择过去的日期
   - 选定后自动显示每日价格明细、折扣和总价
3. **填写信息**：联系人姓名、手机号
4. **费用明细**（实时更新）：
   - 每日价格（区分平日/周末）
   - 连住折扣（3天95折 / 5天9折 / 7天85折）
   - 押金金额
   - 应付总额
5. **取消政策**：
   - 入住前 3 天以上：免费取消
   - 入住前 3 天内：收取 50% 费用
   - 入住当天：不可退款
6. 确认信息后点击"提交订单"
7. 选择支付方式完成支付

> 提示：如果支付前需要登录，登录后会自动恢复已填写的预订信息。

### 5. 管理订单

**订单列表：**
1. 点击"我的" → "我的订单"查看所有订单
2. 订单卡片显示别墅名、日期、金额、状态
3. 已完成且未评价的订单会显示橙色"待评价"标签和"写评价"按钮
4. 点击订单号旁的复制图标可一键复制

**订单详情：**
1. 顶部进度条展示当前阶段：提交订单 → 支付定金 → 商家确认 → 支付尾款 → 入住 → 完成
2. 每个状态下方有行动提示，例如：
   - 待支付："请在24小时内完成支付"
   - 已支付："商家正在确认，预计2-4小时"
   - 已确认："请按时入住，入住时间14:00"
3. 底部有客服联系方式（电话 + 微信）

**取消订单：**
1. 在订单详情页点击"取消订单"
2. 根据取消政策计算退款金额
3. 确认后订单状态变为"已取消"

### 6. 评价别墅

1. 订单完成后，在订单列表点击"写评价"
2. 进入评价页面：
   - 选择评分（1-5星）
   - 编写文字评论
   - 上传图片（可选）
   - 上传视频（可选，需审核通过后展示）
3. 提交后可在别墅详情页看到自己的评价

### 7. 加购增值服务

**轰趴方案：**
1. 首页或别墅详情页浏览推荐的活动方案
2. 方案按场景分类（团建/生日/聚会/亲子），按人数匹配
3. 查看方案步骤和关联套餐，可一键加购

**氛围包：**
1. 按主题打包的装饰和道具（赛博朋克、复古风、露营风等）
2. 预订时可加购

**周边服务：**
1. 厨师上门、摄影跟拍、DJ 驻场等本地服务
2. 浏览服务列表，点击预约

### 8. 趴后回忆（共享相册）

1. 订单完成后，在订单详情页创建共享相册
2. 获得邀请码，通过分享卡片发给朋友（支持复制邀请码/复制链接）
3. 朋友输入邀请码即可加入相册、上传照片
4. 相册上限 200 张照片，有效期 1 年
5. 创建者可设置权限（所有人可上传 / 仅查看）
6. 删除照片需二次确认，不可恢复

### 9. 拼团与AA分摊

**拼团：**
1. 首页查看正在进行的拼团活动
2. 发起或加入拼团，达到人数后享受优惠价格

**AA分摊：**
1. 下单时选择"AA分摊"
2. 设置分摊人数，生成分摊链接
3. 成员通过链接各自支付自己的份额
4. 全员付完后订单自动确认（押金由发起人承担）

### 10. 帮助中心

访问"帮助中心"查看常见问题：
- 如何预订别墅？
- 退款政策是什么？
- 如何参加拼团？
- 如何使用共享相册？
- 入住须知（入住14:00，退房次日12:00）

## 二、商家端（管理后台）

### 1. 登录后台

1. 访问 `平台地址/admin`
2. 输入账号和密码登录
3. 商家角色只能管理自己的数据，平台超管可管理所有商家

### 2. 数据看板

登录后默认进入数据看板，包含：

| 模块 | 说明 |
|------|------|
| 统计卡片 | 本月订单数、本月收入（含环比对比）、待处理事项、用户统计 |
| 趋势图 | 近30天订单和收入趋势 |
| 状态分布 | 各状态订单占比饼图 |
| 热门Top5 | 预订量最高的5个别墅 |
| 最近订单 | 最新订单列表，可直接查看详情，待处理订单橙色高亮 |

**待处理事项**拆分为：待确认订单、待退押金、待审核视频，方便快速定位。

### 3. 房源管理

**添加别墅：**
1. 侧边栏 → 核心运营 → 房源管理 → "新增别墅"
2. 填写基本信息：名称、地址、可住人数、卧室数、面积
3. 设置价格：基础价（平日）、周末价、押金
4. 设置连住折扣：3天/5天/7天折扣比例
5. 上传图片（支持拖拽排序）
6. 选择设施标签
7. 设置标签（团建/生日/聚会/亲子等）
8. 保存后默认下架，确认无误后点击"上架"

**编辑/下架：**
1. 在房源列表找到对应别墅
2. 点击"编辑"修改信息，或切换上架/下架状态

### 4. 房态管理

1. 侧边栏 → 核心运营 → 房态管理
2. 选择别墅，进入日历视图
3. **单日设置**：点击某天，设置当日价格和状态（可预订/不可预订）
4. **批量设置**：选择日期范围，统一设置价格和状态
5. 颜色说明：
   - 绿色：可预订
   - 红色：已预订
   - 灰色：不可预订（商家手动关闭）

### 5. 订单管理

**订单列表：**
1. 侧边栏 → 核心运营 → 订单管理
2. 可按状态筛选订单
3. 订单号支持复制

**处理订单流程：**

| 操作 | 前置状态 | 结果状态 | 说明 |
|------|---------|---------|------|
| 确认订单 | 已支付(1) | 已确认(2) | 确认后系统自动创建分账记录 |
| 拒绝订单 | 已支付(1) | 已拒绝(7) | 需填写拒绝原因，系统触发退款 |
| 确认尾款 | 已确认(2) | 已付全款(3) | 确认用户尾款到账 |
| 标记入住 | 已付全款(3) | 已入住(4) | 用户到店后操作 |
| 标记完成 | 已入住(4) | 已完成(5) | 退房验收后操作，退还押金 |

### 6. 套餐管理

1. 侧边栏 → 商品配置 → 套餐管理
2. 添加套餐加购项（如烧烤套餐、KTV包场等）
3. 设置三档价格：平日价 / 周末价 / 节假日价
4. 用户下单时可选择加购

### 7. 设施管理

1. 侧边栏 → 商品配置 → 设施管理
2. 管理设施字典（如泳池、棋牌室、KTV等）
3. 设施按类别分组
4. 别墅编辑时可关联设施

### 8. 评价管理

1. 侧边栏 → 内容管理 → 评价管理
2. 查看用户提交的所有评价
3. **视频审核**：用户上传的视频需审核通过后才在前台展示
   - 筛选"待审核"视频
   - 预览视频内容
   - 通过：视频在前台展示
   - 拒绝：视频不展示
4. **商家回复**：可对用户评价进行回复
5. 侧边栏菜单有角标提示待审核数量

### 9. 增值服务管理

**活动方案：**
1. 侧边栏 → 增值服务 → 活动方案
2. 创建轰趴剧本模板（团建流程、生日惊喜等）
3. 设置方案步骤和关联套餐

**氛围包：**
1. 侧边栏 → 增值服务 → 氛围包
2. 按主题创建氛围包（物品清单 + 价格）

**周边服务：**
1. 侧边栏 → 增值服务 → 周边服务
2. 添加本地服务商（厨师、摄影、DJ等）

**限定活动：**
1. 侧边栏 → 增值服务 → 限定活动
2. 创建季节限定体验（限时限量）

### 10. 财务与结算

**商家查看财务：**
1. 侧边栏 → 系统管理 → 结算管理
2. 查看：总收入、已结算、待结算金额
3. 每笔订单的分账明细（订单金额、平台佣金、商家实得）

**平台超管结算：**
1. 查看全平台结算记录
2. 确认打款后点击"标记已结算"
3. 商家侧自动更新已结算金额

### 11. 站点配置

1. 侧边栏 → 系统管理 → 站点配置
2. 配置站点名称、Logo、联系方式等基础信息

### 12. 商家管理（仅平台超管）

1. 侧边栏 → 系统管理 → 商家管理
2. 创建新商家：填写商家信息、设置佣金率
3. 为商家创建管理员账号
4. 启用/停用商家

## 三、常见问题

### 用户端

**Q: 预订后多久商家会确认？**
A: 通常 2-4 小时内确认，节假日可能稍慢。超过 24 小时未确认可联系客服。

**Q: 押金什么时候退？**
A: 退房验收无损坏后，商家操作退还押金，1-3 个工作日到账。

**Q: 连住折扣怎么算？**
A: 连续预订 3 天 95 折、5 天 9 折、7 天 85 折，取最优折扣，不叠加。

**Q: 视频评价为什么没显示？**
A: 视频评价需商家审核通过后展示，通常 1-2 个工作日。

### 商家端

**Q: 订单确认后能取消吗？**
A: 已确认的订单不建议取消。特殊情况请联系平台超管处理。

**Q: 如何修改某天的价格？**
A: 进入"房态管理"，点击对应日期，修改价格后保存即可。

**Q: 佣金率可以调整吗？**
A: 佣金率由平台超管设置，如需调整请联系平台。

**Q: 结算周期是多久？**
A: 订单完成后进入待结算，平台超管定期（通常每周）标记结算，具体以合同约定为准。
